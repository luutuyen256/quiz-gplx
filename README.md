# GPLX – ôn thi lý thuyết (web tĩnh)

Bản dựng sẵn, chỉ gồm tài nguyên tĩnh (không có mã nguồn công cụ):

- `index.html` – menu
- `quiz.html` – quiz 600 câu · `quiz-visual.html` – quiz các câu cần xem hình (không có audio)
- `flashcards.html`
- `audio/` – trình nghe audio (mp3 trong `audio/mp3/`)

Chạy thử local: `python -m http.server 8080` rồi mở http://localhost:8080/

Triển khai: GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

Các file ở đây được sinh bởi `tools/publish_site.py` của repo nguồn; không sửa tay.
